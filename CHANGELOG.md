# Changelog

## [9.0.0](https://github.com/cyr-ius/security-review/compare/v8.0.0...v9.0.0) (2026-10-27)


### ⚠ BREAKING CHANGES

* a personal mcp token no longer acts as a ci token on the pipeline routes: create a personal CI token for security-review-ci.
* SECREVIEW_WEB_URL is no longer read. Set SECREVIEW_CONTROLLER_URL on the controller to the root URL (without /ui), or fill in the General settings page.
* **enrollment:** POST /api/v1/enroll, the security-review-mcp enroll command and the request_enrollment tool are removed; request_project replaces the tool for clients with a token.
* **stdio:** security-review-mcp serve --transport stdio no longer starts when SECREVIEW_DATABASE_URL points to PostgreSQL.
* host configurations that start `serve` for stdio must add `--transport stdio`.
* the package is published on PyPI as security-review instead of security-review-mcp; uninstall the old package before installing the new one.
* SECREVIEW_TICKETING_* variables, the ticketing REST routes, the "tickets" field and the third-party connector API (v1) are replaced by their connector names.
* the commands and the setting above are removed.
* **controller:** SECREVIEW_SECRET_KEY_FILE is removed; set SECREVIEW_SECRET_KEY to keep the web sessions across restarts.
* **ci:** rename code-scan and deps-scan to scan-code and scan-deps
* replace SECREVIEW_SERVER_URL to SECREVIEW_MCP_URL
* enrollment requests a project for approval, never a token
* MCP host configurations that start the bare binary must add `serve`.
* /me returns role "user" for a web session; the effective_role field of /users and the role of the login response are removed.
* identify OIDC users by their issuer and subject
* environment variables take precedence over the web interface settings
* tokens are for machines, triager becomes an ordinary role
* the CLI is the only way to the initial admin password
* follow the expected features of the web application standard
* give roles and projects to web users only through groups
* roles, groups and permissions for the web accounts
* run the pipeline commands only through security-review-ci
* `token reset-admin` is replaced by `user reset-password admin`; SECREVIEW_OIDC_SESSION_SECRET/HOURS become SECREVIEW_SESSION_SECRET/HOURS.
* Python 3.14 is now the minimum supported version.
* the HTTP MCP server no longer serves /ui nor the REST API (except the enrollment endpoint); run `security-review-controller serve` next to it and `security-review-controller db upgrade` before starting it.
* SECREVIEW_RULES_DIR is removed; import existing packs with `security-review-mcp rules import <dir>`. list_rules and reload_rules no longer return `rule_packs`.
* SECREVIEW_AUTH_TOKENS, SECREVIEW_AUTH_TOKENS_FILE, SECREVIEW_AUTH_BOOTSTRAP_FILE and SECREVIEW_AUTH_MANAGED_TOKENS_FILE are removed; create tokens with `security-review-mcp token create`. The `token --label/--role` options are replaced by `token create`.
