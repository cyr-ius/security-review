Comptes de l'interface web : locaux (identifiant et mot de passe) ou SSO (fournisseur d'identité)

Seuls ces comptes ouvrent l'interface ; les jetons servent au serveur MCP et à l'API REST. Un changement de rôle ou de projets s'applique immédiatement aux sessions ouvertes ; une réinitialisation du mot de passe ou une suppression les ferme. Le dernier administrateur ne peut être ni supprimé ni rétrogradé. Un utilisateur SSO peut n'avoir aucun rôle propre : le rôle de ses groupes (écran Rôles SSO), relu à chaque connexion, s'applique ; avec les deux, le plus élevé l'emporte.
