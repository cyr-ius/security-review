# Installation

The **Security Review MCP** application consists of a single package named `security-review-mcp`.
This package includes a variant that integrates a `postgres` connector.

Once the package is installed, two binaries become available:
- `security-review-mcp`: the MCP server used by agents.
- `security-review-controller`: a server that hosts the web interface, REST API, database, and administration functions.
See [Two services, two roles](../index.md#two-services-two-roles).

### MCP Server

When the MCP server starts, an SQLite database is created to store reports.
With the `postgres` variant, you can specify a PostgreSQL database instead.

Although you can install the MCP server in a **standalone** mode on a developer's workstation (see [Standalone mode](../advanced/stdio.md)),
we recommend deploying it on a server or within a container connected to a PostgreSQL database.

This approach ensures there is no tight coupling to the underlying MCP technology. You simply need to configure your IDE to connect to the MCP server
via HTTP. See [HTTP Transport](../getting-started/host.md).

For security reasons, an authentication token must be provided to interact with the server.
If no token is present, the MCP server will inform your AI agent about the steps required to obtain one (enrollment).

### Controller Server

Running the `security-review-controller` binary launches an application server,
allowing you to access the database via a web interface. With this application, you can:
- View reports generated by your developer agents
- Propose new rules and checklists
- Share your development standards with the agents
- Track vulnerabilities, conduct security reviews, and manage risk acceptance.

The Controller server also supports a "scan-code" function, which allows for the scanning of an entire repository,
and much more...

## Quick Setup

See the next step: [Deploying the MCP and Controller servers](deploy.md).

## From PyPI

```bash
uv pip install security-review-mcp
uv pip install "security-review-mcp[postgres]"   # with the PostgreSQL driver
```

## Docker Image

To run the server in containers, pull the published image (the `-pg` variant includes the PostgreSQL driver):

```bash
docker pull ghcr.io/cyr-ius/security-review-mcp:latest-pg    # or docker.io/cyrius44/security-review-mcp
```

The same image launches both the MCP server and the controller; see [Docker](../advanced/docker.md).
