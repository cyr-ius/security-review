# User accounts

A user account lets a **person** open the web interface. What it may do comes only from its
**groups**: their roles give its [permissions](access-control.md#what-a-user-may-do).
The machines use [tokens](tokens.md) instead.

The command line, the REST API and the settings are in
[Managing the accounts](../advanced/architecture/controller.md#managing-the-accounts).

| Type | Login | Created |
|---|---|---|
| **Local** | User name and password | By an administrator, on the **Users** screen |
| **OIDC** | Company login ([identity provider](sso.md#oidc-accounts)), no password | By an administrator, or at the first login when the server allows it |

An OIDC account also joins, at each login, the groups that its identity provider names (see
[groups of the identity provider](sso.md#groups-of-the-identity-provider)).

## Password

A password set by someone else (a new local account, a reset by an administrator) is **changed
at the first login**: the interface opens **My account** before anything else.

A chosen password follows the **password policy**: at least 12 characters, with a lowercase
letter, an uppercase letter, a digit and a special character. The screens tick each rule while
you type. A password generated by the interface is shown **only once**.

An OIDC account has no password: it is managed by the identity provider.

## Sessions

- A session lasts 8 hours by default. When it ends, a **Session expired** dialog opens:
  **Log in again** brings you back to the same page.
- **Logging out** closes the sessions of the account in every tab and browser; so does a new
  password or the deletion of the account.
- A change of groups or of roles applies at once, without logging in again.

## Points to watch

- **A lost password** is replaced by an administrator; the very first administrator is created
  at the first start of the controller ([first administrator](../advanced/architecture/controller.md#first-administrator)).
- **A deleted OIDC account is not created again** at its next login, until an administrator
  clicks **Allow again** in **Users**.
- **The last administrator** (holder of `users.manage`) can be neither deleted nor lose that
  permission.
- **A user account never connects an agent**: the agent uses a [personal token](tokens.md#personal-mcp-and-ci-tokens).
